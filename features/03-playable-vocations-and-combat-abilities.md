# Feature: Playable Vocations and Combat Abilities

## Capability Description

Provides distinct playable character classes with specialized attribute pools, basic attacks, resource requirements, and active combat spells/abilities.

## Key Capabilities & Authoritative Seed Rules

- **Magician Vocation:**
  - Attribute profile: Fragile health pool, high mana pool.
  - Basic Attack: Ranged wand spark attack.
  - *Spell 1 (Light):* Casts an illumination aura that increases the player's field-of-view radius for 30 seconds.
  - *Spell 2 (Energy Beam):* High-damage piercing line strike that damages all enemies in a 4-tile linear path.
- **Archer Vocation:**
  - Attribute profile: Balanced health and mana pools.
  - Basic Attack: Standard ranged bow shot requiring clear line-of-sight and consuming physical ammunition (Arrows) from inventory.
  - *Ability (Power Shot):* Heavy single-target physical burst strike on an independent cooldown.

*(Note: Exact damage scaling, cooldown timers, mana costs, and targeting interactions are owned by Stage 3 briefs.)*
