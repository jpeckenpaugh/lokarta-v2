A simple Capstone / Thesis Project Tracker Web App for a student.  Use frameworks, such as Bootstrap for the frontend and FastAPI+SQLite for the backend.  Start with a small set of sections, sources, and milestones as seed data.  The app helps the student track a Praxis/Thesis/Capstone project across research and document work, organizing the document into sections with progress toward word-count targets and milestones, the research into sources with attached notes, and logging advisor feedback and action items.
